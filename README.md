# 📱 Mobile Shopping Portal

A full-featured ecommerce website developed using PHP, MySQL, HTML, CSS and JavaScript.

## 🚀 Features
- User Login & Registration
- Product Listing
- Add to Cart
- Admin Panel
- Responsive Design
- Search Functionality

## 🛠 Technologies Used
- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
